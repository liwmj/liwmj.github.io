🔗 ghlink v0.4.7

GitHub 链路自愈工具：主动监控 GitHub 连通性，异常时自动获取新 IP 写入 hosts，自检回滚 + 多渠道告警。跨平台（Windows / macOS / Linux），核心零依赖。

Windows macOS Linux MIT License
🍎 macOS（Homebrew）
brew tap liwmj/tap
brew install ghlink
🐧 Linux（apt / deb）
echo "deb https://liwmj.github.io/ghlink/apt/ ./" | sudo tee /etc/apt/sources.list.d/ghlink.list
sudo apt update
sudo apt install ghlink
🪟 Windows（安装向导）
下载 ghlink-installer-v0.4.7.exe 并运行（含托盘 GUI）
GitHub 仓库 Release v0.4.7 文档 反馈
