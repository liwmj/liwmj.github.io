ghlink

v0.5.15

GitHub 链路自愈工具：主动探测连通性，网络异常时自动获取可用 IP 写入 hosts，无感恢复访问；内置自检回滚与多渠道告警，跨平台零依赖。

⭐ 1 ⑂ 0 🕒 — Python
📦 安装方式 
brew tap liwmj/tap
brew install ghlink
echo "deb https://liwmj.github.io/ghlink/apt/ ./" | sudo tee /etc/apt/sources.list.d/ghlink.list
sudo apt update
sudo apt install ghlink
下载 ghlink-installer-v0.5.15.exe 并运行（含托盘 GUI）
